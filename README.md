# IBStv

Speler voor je eigen IPTV-abonnement (Xtream Codes) op iPhone, Android, Google TV en Windows.
IBStv levert zelf geen zenders, films of series.

| Map | Inhoud |
|---|---|
| `app/` | de speler zelf (gedeeld door alle versies) |
| `ios/` | iPhone-app (WKWebView + VLC) |
| `android/` | Android- en Google TV-app voor Google Play |
| `demo-server/` | demo-server met legale inhoud voor de keurders |
| `docs/` | supportpagina en privacybeleid (GitHub Pages) |
| `store/` | winkelteksten, afbeeldingen en het stappenplan |

Downloads: zie [Releases](https://github.com/kevinschouten88-web/ibstv/releases).
Begin bij [`store/STAPPENPLAN.md`](store/STAPPENPLAN.md).
